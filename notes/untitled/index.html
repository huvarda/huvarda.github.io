Sample Spaces

  • The set of all possible outcomes of an experiment is the sample space S
  • Individual outcomes are called points
  • The set of all subsets is called the power set P(S)

Events

  • An event is said to occur if the outcome belongs to the event
  • An event E is the subset of another event F if when E happens, F also happens
  • An event is called the intersection of events if it occurs only when both events occur simultaniously
  • Likewise, an event is the union if at least one of them occurs
  • Complement: everything outside of E
  • Difference: If in E-F, it means it is both in E and not in F
  • Certain: Always happens
  • Impossible: Never happens
  • Mutual exclusivity: Intersection is empty set

Laws

  • Commutative, Associative, Distributive
  • De Morgan:
    • (EUF)c=EcFc
    • (EF)c=EcUFc

Axioms of Probability

Let S be the sample space of a random phenomenon. Suppose that to each event A of S, a number denoted by P(A) is associated with A. If P satisfies the following axioms, then it is called a probability and the number P(A) is said to be the probability of A.

Axiom 1

  • P(A) ≥ 0. The probability of any event is >= 0

Axiom 2

  • P(S)=1. The probability of the sample space is 1

Axiom 3

  • If {A1, A2, A3,…} is a sequence of mutually exclusive events (i.e., the joint occurrence of every pair of them is impossible $$ P\left(\bigcup_{i=1}^\infty A_i\right) = \sum_{i=1}^\infty P(A_i). $$Note that the axioms of probability are a set of rules that must be satisfied before S and P can be considered a probability model.

Odds

Odds are an alternative way of expressing probability. “2 to 1 odds” means 2/3 chance, “x to y odds” means x/(x+y)

Selection from Interval

A point is said to be randomly selected from an interval (a, b) if any two subintervals of (a, b) that have the same length are equally likely to include the point. The probability associated with the event that the subinterval (α, β) contains the point is defined to be (β − α)/(b − a).

The probability of selecting a specific value is 0.
