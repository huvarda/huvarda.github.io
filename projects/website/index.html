This Website

Now that it’s my winter break and I have plenty more free time I feel like now’s the perfect time to begin documenting my projects, and where better to start than the making of this website itself?

I’d been wanting to make a new website for some time now. I had made one back in high school using a generic template I found online but I had kinda half-assed that one. It was extremely tedious to update since I was changing the sidebar, menus etc. on each page manually, and I only had a tenuous grasp of CSS. Not to mention the whole website was basically doxxing me, whereas I wanted one that was at least a degree separate from my IRL self.

Here’s a screenshot of that old site. It was basically just a list of projects I’d done, and I plan at some point in the future to port over a few of the pages here, with slight modifications and extra commentary.

Anyways, I began looking into frameworks I could use to make my site. I wanted a basic static website that had limited to no Javascript, just text on a clean background that is easy to navigate and loads quickly. After some research, I came across HUGO, and it was basically exactly what I wanted. HUGO is a framework that lets you write the content of your posts as markdown files, and it automatically formats them. It also makes it easy to generate “list” pages, buttons for next/previous posts, etc.

I tried a few templates from the Themes section on HUGO’s website but none of them were all that great, so I instead opted to make my own theme by starting off with an extremely barebones template and building off of that. Then came the fun part, actually designing the website. Before making this site, I thought I hated CSS, but what I realized was that I had been writing CSS ‘incorrectly’. Instead of eyeballing the CSS like I did back when I was just blindly following tutorials, this time I took a more methodical approach. I first made a color scheme. I then found a website called ‘Penpot’, a free alternative to Figma, to lay out my design.

I tried to keep the colors simple, with a basic dark theme. I made the main ‘category’ divs on the homepage the color I use in Geometry Dash icon set. The diagonal pattern in the background was inspired by the backgrounds of the Stage 5 substages in IWKTK3. I initially wanted to make it animated on all pages but realized it was distracting, so I kept it to only the home page.

When it came to implementing this in CSS, it was far more straightforward than I expected. The only hiccup was with the diagonal background. At first I tried to do it in pure CSS with gradients, but that ended up weirdly warping on the edges of the screen, so I canned that. In the end I just made a small image, tiled it, and animated that instead.

All that was left to do was lay out the homepage and I was done. Or so I thought. I showed the site to my father and he brought up an interesting point. Who is the site for? Well, myself obviously, but also I was planning on sharing this website with recruiters as a sort of portfolio. So I decided, as a last step (which ended up being the most difficult to figure out!), to make a sort of “serious mode” with a slightly more detailed blurb on the homepage and a higher emphasis on the ‘projects’ section compared to everything else. To achieve that, I made it so that if “serious=true” is in the query string of the url, there is a tiny script that adds the class ‘serious’ to the html element. The rest of the logic is handled by hiding/showing various elements in pure CSS. If you’re checking the site out normally and want to see the ‘serious’ version, click here.

So yeah, that’s a bit of insight into how I made this website!
